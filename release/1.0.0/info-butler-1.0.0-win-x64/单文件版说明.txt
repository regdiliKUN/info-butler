信息管家 v1.0.0 · 单文件 EXE 版
================================================================

【这是什么】
  信息管家.exe 是把「信息管家」整个本地应用（界面、样式、全部脚本、图标）
  与本地 HTTP 服务、Node 运行时一起打包成的单文件程序。
  不需要安装 Node.js、Python 或任何运行库，双击即用。

【怎么用】
  1. 双击「信息管家.exe」（桌面 / 开始菜单的快捷方式已经指向它）
  2. 会出现一个服务窗口，显示访问地址，并自动打开默认浏览器
     （若浏览器没自动打开，手动访问窗口里显示的地址，默认 http://127.0.0.1:4173/）
  3. 用完后，关闭那个服务窗口即停止服务

【数据在哪】
  数据保存在浏览器的 localStorage，绑定 http://127.0.0.1:4173 这个地址。
  与旧版「启动应用.bat」用的是同一份数据，切换过来后原有记录不会丢。
  换浏览器、换端口或清理浏览器数据都会导致记录不可见，
  建议在「设置 → 数据管理」定期导出 JSON 备份。

【命令行参数】（可选）
  信息管家.exe --port 5000     换一个端口启动（默认 4173）
  信息管家.exe --no-browser    只启动服务，不自动开浏览器
  信息管家.exe --version       查看版本
  信息管家.exe --help          查看帮助

【端口占用怎么处理】
  若 4173 上已经有信息管家在运行 → 直接打开已有窗口，不会重复起服务。
  若 4173 被别的程序占用 → 自动顺延到 4174、4175…（注意：不同端口的数据是相互独立的）。

【和包内其它文件的关系】
  · 旧的「启动应用.bat」「创建桌面快捷方式.bat」已移除，启动一律走 信息管家.exe。
  · index.html / css / js / icon.* 是原应用前端源码，仍保留在本目录，
    仅作为 EXE 的构建素材与查阅用，日常使用不需要它们。
  · start.sh / install-shortcuts 是 macOS / Linux 下的旧启动脚本（需系统已装 node 或 python3），
    Windows 上不用理会。
  · 如需重建桌面 / 开始菜单快捷方式：node scripts\install.js（会指向 信息管家.exe）

【首次运行提示】
  该 EXE 未做代码签名（打包时改写过 PE 资源，原签名已失效）。
  若 Windows SmartScreen 拦一下，点「更多信息 → 仍要运行」即可。
