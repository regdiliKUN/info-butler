数据管理

数据保存在本机浏览器本地存储中。建议定期导出备份。

「导入文档」支持 Word（doc / docx / docm / dot / dotx）、WPS（wps / wpt）、 RTF、ODT、网页（html）、纯文本与代码（txt / md / log / xml / srt / ini 等）、表格（csv / tsv，转成表格）、 Excel 电子表格（xls / xlt / et / xlsx / xlsm / xltx / xltm，多工作表转成 Markdown 表格）与 OpenDocument 表格（ods / ots）， 以及 json 备份。 编码自动识别 UTF-8 / GBK / UTF-16；扩展名写错也能按内容识别（例如把 docx 存成了 .doc）。 扫描件（整页是图片）没有文字层，无法提取。
