# 待办池（发现但尚未处理）

按「价值 ÷ 成本」排序。每轮从顶部取，不要跳着做。

## 高价值

- **大模型流式输出**：现在 `stream: false`，长回答要等到全部生成完才显示。
  改 SSE 后首字延迟能从 3–8 秒降到 0.5 秒内。
- **提醒 / 到期通知**：`dueDate` 只展示不提醒。用 Notification API 做本地到期提醒（需可关闭）。
- **数据存 IndexedDB**：localStorage 上限 5MB，2000 条 20KB 的记录就满了。
  迁到 IndexedDB 可突破上限，但要做 localStorage 兜底与迁移。

## 中价值

- **批量操作**：勾选多条 → 改类型 / 打标签 / 删除。
- **卡片右键菜单**：常用操作埋在卡片底部的小按钮里。
- **搜索历史**：命令面板没有"最近搜过什么"。
- **自绘 prompt 对话框**：标签重命名还在用原生 `window.prompt`，样式割裂。
- **时间表达式扩充**：「上周」「这个月」「三天前」这类相对时间还不能用于筛选。
- **拼音检索**：`zgll` → 知识管理。
- **阶段总结的趋势对比**：现在只说"这段时间有多少"，不说"比上期多了还是少了"。
- **xlsx 多表合并策略**：多工作表目前全部拼接，长表会撑爆单条上限。
- **导入进度**：批量导入大文件时没有逐文件进度。

## 低价值 / 待观察

- 多库（工作 / 生活分离）
- 单条记录分享为只读 HTML
- 打印样式
- 英文界面
- 记录模板（会议纪要 / 读书笔记 / 周报）
- 关联图谱可视化
- 使用 Web Worker 把分词与关联移出主线程（当前 2000 条已降到 200ms，暂不必要）
