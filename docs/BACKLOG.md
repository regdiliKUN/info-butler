# 待办池（发现但尚未处理）

按「价值 ÷ 成本」排序。每轮从顶部取，不要跳着做。

## 高价值

- **列表重渲染会吞掉焦点**：分批渲染的 IntersectionObserver 自动补页时整块重建 DOM，
  键盘用户正在聚焦的卡片标题会被摘掉，接着按 Enter 什么也不会发生（e2e 偶发失败暴露的正是这个）。
  修法：`renderStream` 后按 `data-id` 把焦点还给原来那条记录。
- **数据存 IndexedDB**：localStorage 上限 5MB，2000 条 20KB 的记录就满了。
  迁到 IndexedDB 可突破上限，但要做 localStorage 兜底与迁移。

## 中价值

- **流式回答不能中途停**：现在只能等它说完。缺一个「停止生成」按钮（已有 AbortController，接上 UI 即可）。
- **阶段总结仍是整段生成**：可复用 `streamOnce`，但边生成边渲染 Markdown 会抖（表格/列表反复重排），
  需要先定策略：流式只显示纯文本，结束后再统一排版。
- **通知只在启动时检查一次**：应用长期开着不关，跨天后不会再提醒。
  可在 `visibilitychange` 回到前台时补一次，仍受「每天一次」去重约束。
- **卡片右键菜单**：常用操作埋在卡片底部的小按钮里。
- **拼音检索**：`zgll` → 知识管理。
- **阶段总结的趋势对比**：现在只说"这段时间有多少"，不说"比上期多了还是少了"。
- **xlsx 多表合并策略**：多工作表目前全部拼接，长表会撑爆单条上限。
- **导入进度**：批量导入大文件时没有逐文件进度。

## 低价值 / 待观察

- 多库（工作 / 生活分离）
- 单条记录分享为只读 HTML
- 打印样式
- 英文界面
- 记录模板（会议纪要 / 读书笔记 / 周报）
- 关联图谱可视化
- 使用 Web Worker 把分词与关联移出主线程（当前 2000 条已降到 200ms，暂不必要）
