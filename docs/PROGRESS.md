## 第 2 批 · 引擎正确性（P2）

- **006 · P2 · 修分词丢弃连字符** — `GPT-4` 被切成 `gpt`，搜「gpt-4」永不命中。正则改为保留连字符的 `[a-z][a-z0-9+#.]*(?:-[a-z0-9.]+)*`。验证：单测断言 `gpt-4` 整体成词。
- **007 · P2 · 修短句被误判为待办** — 旧规则给「少于 45 字」无条件 +0.7，导致 38 字的观点被判成待办；且「做/约/买」这类单字出现在任意位置都算信号。改为：短句不加分；单字动词只在句首算信号；明确时间只在「已经像待办」时才加强。验证：14 条真实语料回归表全部通过。
- **008 · P2 · 分类打分可观测** — 新增 `Engine.classifyScore()`，把三类得分暴露出来，单测失败时能直接看到是哪条规则带偏了。
- **009 · P2 · 分词补二元组兜底** — 词典只有几百词，短句里一旦没有词典词就被整句丢掉：「明天下午三点前把 Q4 路线图发给张总…」旧实现只抽出 `q4` 一个词，检索与关联全废。改为词典最大匹配 + 未登录片段用字符二元组滑动兜底。验证：同句抽出 18 个词。
- **010 · P2 · 过滤虚词二元组** — 二元组会产出「的投」「图不」「要只」这类跨词碎片，既污染索引又让无关记录因共享碎片而显得相关。含虚词单字的二元组不入索引（词典成词不受影响）。验证：单测断言 `的投` 不出现。
- **011 · P2 · IDF 平滑** — 经典 `log(N/df)` 在只有两条记录时会把「两条都含有的词」权重压成 0，恰好抹掉了「它们讲同一件事」这个最强信号。改为 `log(1 + N/(df+0.5))`，恒为正。验证：两条同主题短文相似度从 0 升到 0.27。
- **012 · P2 · 索引缓存签名碰撞** — 旧签名是「条数 | 最后更新时间 | 首条 id」，导入一批条数与时间戳都相同的新数据时会复用旧索引。改为对全部 `id + updatedAt` 做 FNV-1a 累积哈希。验证：单测「条数相同内容全换」场景通过。
- **013 · P2 · 关联打分改「余弦 + 包含度」** — 纯余弦会被长度差异惩罚，两条 30 字的相关笔记相似度掉到阈值以下，导致「相关内容」长期为空。新增包含度（短文本被覆盖的比例，按 TF-IDF 权重加权，再用共享词数打折）。验证：4 组判定表 4/4 正确，无关对仍为 0。
- **014 · P2 · 标签抽取与索引分词分离** — 标签要"像词"，索引要"覆盖全"。新增 `tokenizeWords()` 只取词典成词供标签使用，索引仍走二元组；二字词共享一个字视为同一处文字的碎片并去重。验证：单测「标签不含天下」通过。

## 第 4 批 · 数据安全（P1）

- **016 · P1 · 删除改为软删除 + 回收站** — 本地应用没有服务端兜底，误删就是永久丢失。`Store.remove()` 改为移入回收站（带 `deletedAt`），新增 `trash / restore / purge / emptyTrash / trimTrash`；保留 30 天或最多 80 条。验证：单测覆盖「删除→回收站→恢复→字段完整」全链路。
- **017 · P1 · 撤销栈 + Ctrl+Z** — 每次增删改前把记录集快照进内存栈（上限 20 步，不落盘以免二次占用配额）。界面加 `Ctrl/⌘+Z`，并刻意跳过输入框内的按键——否则打字时按撤销会误删记录。验证：单测「撤销删除」+ e2e「点完勾选按 Ctrl+Z 状态翻回来」。
- **018 · P1 · 导入按内容指纹去重** — 同一份备份导入两次会把记录翻倍。新增 FNV-1a 指纹（类型 + 归一化正文），导入时跳过已存在的指纹，并区分「重复」与「无效」两类跳过。验证：单测「重复导入 added=0 / duplicated=1」。
- **019 · P1 · 配额写满时的自救与告知** — 写库失败曾经只在控制台打日志。现在：先清回收站里较旧的条目再重试一次，仍失败才把可操作提示（导出 / 清理）弹给用户。验证：单测用 400 字节配额的假 localStorage 触发失败并断言提示文案。
- **020 · P1 · 数据完整性修复** — `Store.repair()` 在载入时体检：剔除空正文、去重 id、收敛非法类型/优先级、截断超长正文、剔除指向不存在记录的悬空关联。验证：单测构造 4 条脏数据，修复后条数、id 唯一性、类型收敛均符合预期。
- **021 · P1 · schema 版本与迁移入口** — 新增 `info_butler_meta_v1` 存 `schemaVersion`，`migrate()` 从 v1 升到 v2 时补齐指纹等新字段。老 localStorage 与老备份都能直接用。验证：单测断言 meta 写入。
- **022 · P1 · 导出 Markdown** — 按类型分组，保留完成状态、截止日、重点标记与标签，可直接粘进任何笔记软件。验证：单测断言分组标题与状态文案。
- **023 · P1 · 导出 CSV** — 带 UTF-8 BOM（Excel 打开不乱码），正确转义逗号与引号。验证：单测断言 BOM 首字节与 `""引号""` 转义。
- **024 · P1 · Toast 支持动作按钮** — 原来的提示只能看不能点。现在可挂一个动作（如「撤销」），带动作时停留 6 秒而不是 2.4 秒。验证：e2e 删除后点提示里的「撤销」能恢复记录。
- **025 · P1 · 设置页回收站面板** — 列出被删记录（标题、类型、删除于几天前），支持单条恢复 / 彻底删除 / 清空。验证：e2e 打开设置页断言回收站区域有内容。
- **026 · P1 · 存储用量可视化** — 设置页显示「已用 X KB / 约 5 MB（N%）」进度条，60% 转黄、84% 转红；超过 4.2MB 时主动提示（同一条提示 5 分钟内只弹一次，否则每次保存都弹）。验证：e2e 断言用量文案出现。
